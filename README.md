# CodeAlpha E-commerce Store

## Project Description
A simple full stack e-commerce website built for CodeAlpha Internship.

## Features
- User Login/Register
- Product Listing
- Product Details Page
- Shopping Cart
- Order System

## Tech Stack
Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express  
Database: MongoDB  

## How to Run
1. npm install
2. npm start
